# my-own-website

Personal portfolio site built with Next.js, TypeScript, and Tailwind CSS. Hosted on Vercel.

- Edit site content in `src/data/resume.ts`.
- Change the accent color in `src/app/globals.css` (`--color-accent`).
- See `PLAN.md` for the full plan.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
